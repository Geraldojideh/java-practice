# Unit 3 Chapter 4 Question 2 - One Hundred and Eighty!

Write a program that keeps reading turns, one per line, until a turn totals exactly 180.

## Input Specification
Each turn contains three lines of input (for the three darts) that are integers from 0 to 60. A turn totalling 180 will always appear. There may be lines of input that appear are the turn totalling 180 appears. These should be ignored. 

## Output Specification
Print two lines in exactly this format:
```
It took N turns to hit 180.
Total points thrown: P
```

`N` is the number of turns thrown, including the 180 turn. If `N` is `1`, print `turn` instead of `turns`. `P` is the sum of every dart in every turn, including the 180 turn. Stop reading as soon as you reach the 180 turn; any lines after it are ignored.


## Sample Input 1
```
20
5
1
60
20
20
60
60
60
```



## Sample Output 1
```
It took 3 turns to hit 180.
Total points thrown: 306
```


## Explanation for Sample Output 1
The three turns scored `26`, `100`, and `180`.


## Sample Input 2
```
60
60
60
```

## Sample Output 2
```
It took 1 turn to hit 180.
Total points thrown: 180
```
