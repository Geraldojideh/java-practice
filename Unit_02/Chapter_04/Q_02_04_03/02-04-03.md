# Unit 3 Chapter 4 Question 3 - Hit the Bullseye

A dart-throwing robot reports where each dart lands as two integers, x and y, in millimetres from the bullseye at (0, 0). Negative x is left of the bull and negative y is below it. The robot's judging circuit measures a dart's distance from the bull by adding the horizontal and vertical misses: $distance = |x| + |y|$. A dart counts as a bullseye if its distance is $10$ mm or less.

Write a program that keeps reading darts, one per line, until a dart is a bullseye, then prints how many darts were thrown and the distance of that bullseye dart. Use <a href="https://docs.oracle.com/javase/8/docs/api/java/lang/Math.html#abs-double-">`Math.abs()`</a>.

`Math.abs(-7)` and `Math.abs(7)` both return `7`.


## Input Specification
Each line holds one dart: two integers `x` and `y`, each from `-500` to `500`. A bullseye dart will always appear.

## Output Specification
Print two lines in exactly this format:

```
Darts thrown: N
Bullseye distance: D
```

$N$ is the number of darts thrown, including the bullseye dart. $D$ is the distance of the bullseye dart. Stop reading as soon as you reach it; any lines after it are ignored.

## Sample Input 1
```
12 -5
-30 40
4 -3
```

## Sample Output 1
```
Darts thrown: 3
Bullseye distance: 7
```

## Explanation for Sample Output 1
The distances are `17`, `70` and `7`, so the third dart is the first bullseye.

## Sample Input 2
```
-6 4
```

## Sample Output 2
```
Darts thrown: 1
Bullseye distance: 10
```


## Explanation for Sample Output 2
The distance is `6 + 4 = 10`, so this dart is a bullseye.
