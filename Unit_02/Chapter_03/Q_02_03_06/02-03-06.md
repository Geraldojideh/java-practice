# Unit 2 Chapter 3 Question 6 - First and Third Occurrences

Use a for loop method to find the first and third occurrences of a substring in a user inputted String. Output the indexes at which these occurreences occur in the String. The inputs and outputs are case sensitive.

Note: use of the indexOf() method is **not allowed** for this question.

## Input Specification

The input consists of two inputs. The first is a string $S$. The second is the substring $S_1$ whose first and third occurrences in the larger string are to be found. It is guaranteed that there will at least be three occurrences of the substring $S_1$ in the String $S$.

## Output Specifications

On separate lines, output `First occurrence: [index1]` and `Third occurrence: [index2]`, where `index1` is replaced with the index of the first occurrence of the substring, and `index2` is replaced with the index of the third occurrence of the substring. 

## Sample Input 1

```
The quick brown fox jumps over the lazy dog. 
o
```

## Sample Output 1

```
First occurrence: 12
Third occurrence: 26
```

## Explanation for Sample Output 1

The letter `o` appears in the phrase `The quick brown fox jumps over the lazy dog.` four times. The first occurrence of the substring is at index 12, while the third occurrence is at index 26. 

## Sample Input 2

```
Doodling dachsunds is delightful.
d
```

## Sample Output 2

```
First occurrence: 3
Third occurrence: 16
```

## Explanation for Sample Output 2

The question is case sensitive, so the `d`'s first occurrence isn't until index 3. The third occurrence is at index 16.
