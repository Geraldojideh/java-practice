# Unit 2 Chapter 3 Question 4 - Luna's Leaps

Luna the cat is bored of walking across the living room, so she has lined up a row of numbered cushions and decided to hop across them instead! Luna starts on cushion $A$ and wants to reach cushion $B$, but she is feeling lazy and will only land on every $K$-th cushion.

Use a for loop to output the number of each cushion Luna lands on, from $A$ to $B$ (inclusive), hopping $K$ cushions at a time.

## Input Specification

The input consists of three lines. The first line contains an integer, $A$, the cushion Luna starts on. The second line contains an integer, $B$, the last cushion Luna is allowed to land on. The third line contains an integer, $K$, the number of cushions in each hop. It is guaranteed that $1 \le A \le B \le 1000$ and $K \ge 1$.

## Output Specifications

Output the number of every cushion Luna lands on, starting with $A$ and hopping $K$ cushions at a time without going past $B$. Each number should occupy its own line of output.

## Sample Input 1

```
1
10
3
```

## Sample Output 1

```
1
4
7
10
```

## Explanation for Sample Output 1

Luna starts on cushion 1, then leaps 3 cushions to cushion 4, then again to cushion 7, and finally to cushion 10. Cushion 10 is the last possible cushion that Luna can leap on without touching the carpet, which is definitely lava. 

## Sample Input 2

```
5
10
2
```

## Sample Output 2

```
5
7
9
```

## Explanation for Sample Output 2

Luna starts on cushion 5, then leaps 2 cushions to cushion 7, then again to cushion 9. She stops there, as another leap would bring her past the last cushion, onto the hot scalding lava below. 🌋😿
