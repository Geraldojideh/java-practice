# Unit 2 Chapter 3 Question 3 - Meow Meow
Luna the cat is very excited today! Maybe she knows that a new jar of catnip is in the closet?

Use a for loop to output `meow` $N$ number of times to the console, where $N$ is a user-inputted integer.

## Input Specification
The input consists of a single line containing a positive integer, $N$. It is guaranteed that $N \ge 0$.


## Output Specifications
Output `meow` $N$ number of times, with each `meow` occupying its own line of output.

## Sample Input 1

```
2
```

## Sample Output 1

```
meow
meow
```
